# Superstitions en Chine 🇨🇳

Une application interactive et immersive explorant les superstitions fascinantes de la culture chinoise.

## 🚀 Fonctionnalités

- **Narration interactive** : Découvrez les superstitions à travers plusieurs scènes thématiques.
- **Design Premium** : Animations fluides avec Framer Motion et une esthétique soignée.
- **Réactif** : Optimisé pour une expérience fluide sur tous les appareils.

## 🛠️ Technologies utilisées

- **React 19**
- **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide React** (Icônes)

## 📦 Installation et Lancement

1. Clonez le dépôt :
   ```bash
   git clone [URL-DU-REPO]
   ```

2. Installez les dépendances :
   ```bash
   npm install
   ```

3. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```
